# Bostan

A static, mobile-first website for a fictional vegan restaurant in Cluj-Napoca,
built with Bootstrap 5.3 for a university web design assignment.

## Files

- `index.html`: the page
- `assets/css/style.css`: custom styles on top of Bootstrap
- `assets/js/main.js`: "now serving" sticker, menu tabs, lunch carousel, counters, gallery lightbox, lazy map
- `assets/vendor/`: Bootstrap CSS and JS bundle
- `assets/fonts/`: self-hosted web fonts
- `CREDITS.md`: photo sources and licences

## Elements

Required: collapsible navbar with logo, one colour scheme, footer with contact details and social links,
photo gallery with lightbox, cards (menu dishes), features and testimonials, carousel (lunch of the day).

Optional: Google Maps embed, animated counters, accordion (questions).

## Publish on GitHub Pages

1. Upload these files to the root of a public repository.
2. Settings, Pages, Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
3. The site appears at `https://<username>.github.io/<repository>/`.
