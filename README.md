# Garden Table

A static, mobile-first website for a fictional vegan restaurant in Cluj-Napoca,
built with Bootstrap 5.3 for a university web design assignment.

## Files

- `index.html`: the page
- `assets/css/style.css`: custom styles on top of Bootstrap (colours are at the top, in `:root`)
- `assets/js/main.js`: "now serving" stamp, menu tabs, lunch of the day carousel, counters, gallery lightbox, lazy map
- `assets/img/`: optimised photos (hero, menu, lunch, gallery) and the favicon
- `assets/vendor/`: Bootstrap CSS and JS bundle
- `assets/fonts/`: self-hosted web fonts
- `CREDITS.md`: photo sources and licences

## Elements

Required: collapsible navbar with logo, one colour scheme, footer with contact details and social links,
photo gallery with lightbox, cards (menu), features and testimonials, carousel (lunch of the day).

Optional: Google Maps embed, animated counters, accordion (questions).

## Publish on GitHub Pages

Upload the contents of this folder (including `assets`) to the root of the repository,
then Settings, Pages, "Deploy from a branch", `main`, `/ (root)`.
